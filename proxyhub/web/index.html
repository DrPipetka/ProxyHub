Обновление подписок

Интервал отсчитывается от завершения попытки. Неизменившиеся конфиги сохраняют результаты проверок и паузу после ошибок. 0 минут — только вручную.

Настройки всех подписок

Применяется ко всем сохранённым подпискам. Очистка удаляет только исчезнувшие конфиги после успешной загрузки без ошибок разбора. Галочка сохранения рабочих действует при включённой очистке; проверяемые конфиги тоже сохраняются до следующего обновления. Ручные импорты и конфиги старой версии без связи с подпиской сохраняются.

API ProxyHub

Выберите маршрут, изучите параметры и выполните запрос к этой установке. Внешний клиент использует Authorization: Bearer <token>; панель может использовать текущую сессию.

400 — параметры, 401 — авторизация, 403 — источник запроса, 404 — нет прокси или записи, 409 — конфликт, 413 — размер тела, 503 — ядро или порты. Ошибка: {"error":"code","message":"..."}.

Настройки приложения
Параметры со знаком ↻ вступают в силу после перезапуска.
Постоянный прокси
Один SOCKS5-адрес без срока аренды. При сбое приложение автоматически выбирает другой рабочий конфиг. Если нужный сайт недоступен через текущий сервер, нажмите «Сменить конфиг» и повторите подключение.
Загрузка состояния…
Адрес: —
Параметры ниже применяются после нажатия «Сохранить». Для работы нужен хотя бы один проверенный конфиг, для смены — другой доступный конфиг. При отключении работы прокси соединения закрываются.
Очистка базы
Удаляет конфиги и историю проверок, закрывает соответствующие SOCKS5. «Вся база» также удаляет все подписки и останавливает их обновления. Настройки приложения сохраняются.
