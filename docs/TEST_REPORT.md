# Результаты проверки — 28 октября 2026

Среда: Windows x64, Python 3.13.13, xray-core 26.10.21. Зависимости зафиксированы в `requirements-lock.txt`.

## Функциональность

- 57 автоматических тестов: парсеры, настройки, API и безопасность, состояния, таймеры, конкурентные аренды, дедупликация, планировщик, ошибки тестовых URL, UDP и ограниченный замер скорости.
- Интеграционные проверки на настоящем xray: динамическое добавление/удаление SOCKS5 без смены PID пула, закрытие порта менее чем за 2 секунды, один процесс проверки на пачку и завершение дочерних процессов.
- В браузере: вход, дашборд, форма настроек, импорт двух синтетических ошибочных строк, корректные статусы/причины, маскирование ссылок, журнал событий и отсутствие ошибок JavaScript. Проверочные строки удалены после проверки.
- Автоматическая загрузка xray с SHA256 и базы DB-IP Country Lite успешно прошла.

## Нагрузка

Синтетическая база 100 000 уникальных VLESS-ссылок, диск проекта Z:. Проверка под профилировщиком Python, без внешнего прокси-трафика:

| Метрика | Результат |
|---|---:|
| Принято конфигов | 100 000 |
| Импорт | 34,133 с |
| Первая страница API | 69,23 мс |
| Последняя страница | 53,40 мс |
| Фильтр состояния/источника | 59,28 мс |
| Поиск по серверу | 107,40 мс |
| Пиковый RSS Python-процесса | 141,80 МБ |

До изменения частоты checkpoint WAL импорт занимал 137–150 секунд. Исходные окончательные метрики находятся в `benchmark.json`. Результат зависит от диска, ОС и сложности конфигов.

## Что требует проверки с рабочими узлами

Не подтверждены без реальных пользовательских конфигов: проверка 1000 удалённых узлов за 15 минут, заполнение/восстановление живого пула, точность замера скорости на разных сетях и суммарная память с 50 активными прокси под нагрузкой. Не выполнялся запуск на Linux, ARM64 и отдельной Windows 10. Для этих сценариев есть `ACCEPTANCE.md`; они не подменяются синтетическими тестами.

В текущей версии Starlette есть предупреждение об устаревании httpx в TestClient. Оно относится к тестовому клиенту; все проверки выполняются. Рабочий SOCKS-клиент приложения использует httpx[socks].
